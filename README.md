# Reverse Solitaire v0.1.13

高校生の頃に考えた「記憶 + ソリティア」型トランプゲームです。

## 現在のルール

1. 通常のトランプ52枚をシャッフルします。
2. 1組6枚を基本として、6枚×8組 + 最後の4枚の1組、合計9組に分けます。
3. 各組のカードは上下にずらして重ねます。
4. 初期状態では各組のカードを表・裏・表・裏...と交互に配置します。
5. 「ひっくり返す」は、実物のトランプの束を机の上でドミノ倒しのように上下へ180°倒す動作です。
   - 下方向へひっくり返すと、山全体が支点を越えて下側へ移動します。
   - **カードの上下の並び順は完全に逆順になります。**
   - 同時に、**各カード自身の表裏もすべて反転**します。
   - 反転前に数字・マークが見えていたカードは表の柄（カード裏面）になり、反転前に表の柄だったカードは数字・マークが見えるようになります。
   - 次に上方向へひっくり返すと、上下順が再び逆転し、各カードの表裏も再度反転して、取り除かれていないカードは元の状態へ戻ります。
6. 選択できるのは、その山で見た目上一番上にあるカードです。裏向きの場合も、覚えている数字を頼りに選択できます。
7. 1枚目を選び、2枚目をクリックした時点で同じ数字なら自動的に2枚を取り除きます。スートは違っていて構いません。
8. ペアが違った場合は短いフィードバックの後に選択を解除します。
9. 全52枚を取り除けばクリアです。
10. 続行困難と判断したら「ギブアップ」で終了できます。

## カード表示

- 表向きカードは、実際のトランプのように **左上と右下の両方へ数字・マークを表示**します。
- 2枚目以降のカードも、下側の白い露出部分から数字・マークを確認できます。
- カード外周は角丸風で、影・内側の余白・中央スート表示を使って見やすくしています。
- 裏面も単色ではなく、内枠と控えめな斜線パターンでカードらしく見えるようにしています。

## 操作性

- 誤ったペアを選択した時の効果音は、短く控えめな音です。v0.1.13 では v0.1.12 より少しだけ音量を上げました。
- ツールバーの **「消音」** をオンにすると、誤選択時の効果音を鳴らしません。
- 各組の **「ひっくり返す ↓/↑」ボタンは、反転前の山と反転後の山の中間にある支点位置へ固定**しています。
- カード束は反転時にそのボタン位置を横切って反対側へ移動するため、上向き・下向きを繰り返してもマウスを移動せず操作できます。

## 4枚の基準例

反転前が上から次の4枚の場合:

1. A♣（数字・マーク表示）
2. カードA（表の柄）
3. 9♥（数字・マーク表示）
4. カードB（表の柄）

下へひっくり返した後は、上下順が逆転し、各カードの表裏も反転して上から次の順になります。

1. カードB（数字・マーク表示）
2. 9♥だったカード（表の柄）
3. カードA（数字・マーク表示）
4. A♣だったカード（表の柄）

つまり、**順番は逆順、各カードの表裏も反転**が基準ルールです。

## アニメーション

- 初回は `ひっくり返す ↓` で、山全体が下方向へ倒れ込みます。
- 約90°でカード束がほぼ線になる瞬間に、カード順と各カードの表裏を切り替えます。
- 次回は `ひっくり返す ↑` で上側へ戻り、もう一度逆順＋表裏反転します。
- ペア成立時は、2枚のカードが縮みながら消えるアニメーションを表示します。

### ちらつき対策

Tkinter Canvas のフレーム更新では、旧フレームを先に全面消去せず、次フレームを完成させてから旧フレームを破棄します。
途中の空画面をユーザーへ見せない疑似ダブルバッファ方式を維持しています。

## 起動方法（Windows）

```bat
run_game.cmd
```

または:

```bat
py src\reverse_solitaire\app.py
```

## 回帰テスト

```bat
check_harness.cmd
```

`pytest` が未インストールの場合は `check_harness.cmd` が自動インストールを試みます。

## 開発ガードレール

ゲームルール上の不変条件は `harness/app_blueprint.yaml` に記録しています。
ルール変更を伴わない修正では、この不変条件と既存テストを維持します。
