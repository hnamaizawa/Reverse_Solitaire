# Reverse Solitaire v0.1.18

高校生の頃に考えた「記憶 + ソリティア」型トランプゲームです。

## 現在のルール

1. 通常のトランプ52枚をシャッフルします。
2. 1組6枚を基本として、6枚×8組 + 最後の4枚の1組、合計9組に分けます。
3. 各組のカードは上下にずらして重ねます。
4. 初期状態では各組のカードを表・裏・表・裏...と交互に配置します。
5. 「ひっくり返す」は、実物のトランプの束を机の上でドミノ倒しのように上下へ180°倒す動作です。
   - 下方向へひっくり返すと、山全体が支点を越えて下側へ移動します。
   - **カードの上下の並び順は完全に逆順になります。**
   - 同時に、**各カード自身の表裏もすべて反転**します。
   - 次に上方向へひっくり返すと、上下順が再び逆転し、各カードの表裏も再度反転して、取り除かれていないカードは元の状態へ戻ります。
6. 選択できるのは、その山で見た目上一番上にあるカードです。裏向きの場合も、覚えている数字を頼りに選択できます。
7. 1枚目を選び、2枚目をクリックした時点で同じ数字なら自動的に2枚を取り除きます。スートは違っていて構いません。
8. ペアが違った場合は短いフィードバックの後に選択を解除します。
9. 全52枚を取り除けばクリアです。
10. 続行困難と判断したら「ギブアップ」で終了できます。

## v0.1.18 の追加機能

### 完全消音

- ツールバーの **「消音」** はマスター消音です。
- 誤選択音、クリア音、今後追加するBGM/効果音を含め、ゲームが鳴らす音をすべて停止します。
- 音が鳴っている途中で消音に切り替えた場合も、その時点で停止します。
- ヒント、ギブアップ確認、ゲームクリア、Undo通知は Windows の標準 MessageBox を使わず、アプリ内の独自ダイアログで表示します。
- そのため、**消音モード中に Windows 標準ダイアログの通知音が漏れることもありません。**

### イージーモード

- ツールバーの **「イージー（次ゲーム）」** をオンにしてから「新しいゲーム」を押します。
- 通常と同じ52枚、同じ9組（6枚×8組 + 4枚）を使います。
- ただし、**1つの組の中に同じ数字が2枚以上入らないように配ります。**
- カードの表裏交互配置、反転方法、ペア削除ルールは通常モードと同じです。
- 現在イージーモードで遊んでいる場合はステータス欄に「イージー」と表示します。

### Undo

- ツールバーの **「Undo」** で直前のゲーム操作を1回だけ戻せます。
- 対象は次の操作です。
  - 山のひっくり返し
  - 成立したペアの削除
  - ギブアップ
- カードの並び、各カードの表裏、山の上下側、手数、削除済みペア数、ゲーム終了状態をまとめて元に戻します。
- 新しいゲームを開始するとUndo履歴はクリアされます。

## カード表示

- 表向きカードは、実際のトランプのように **左上と右下の両方へ数字・マークを表示**します。
- 2枚目以降のカードも、下側の白い露出部分から数字・マークを確認できます。
- カード同士の縦方向のずれを広めにし、8 と 9 のような数字も判別しやすくしています。
- 右下の数字・マークは中央の「ひっくり返す」ボタンと重なりにくい位置へ寄せています。

## 操作性

- ツールバーの **「ヒント」** を押すと、現在削除可能な同じ数字のペアがあるかだけ確認できます。
- ヒントは「ある／ない」だけを表示し、どの組同士かは表示しません。
- 各組の **「ひっくり返す ↓/↑」** ボタンは、反転前後の山の中間にある支点位置へ固定しています。
- 反転アニメーションは約0.17秒で、小気味よく連続操作できます。

## クリア演出

- 最後のペアを取り除くと、`CLEAR!` の表示とスート・星の放射演出を表示します。
- 同時に短い上昇ファンファーレを再生します。
- ファンファーレは誤選択音より控えめな音量です。
- 消音中はファンファーレも鳴りません。

## 1ファイルEXE版

Windowsでは PyInstaller の one-file モードを使い、**`ReverseSolitaire.exe` 1ファイルだけで動作する配布版**を作成できます。
配布先PCには Python のインストールは不要です。

### EXEの作成

```bat
build_exe.cmd
```

生成先:

```text
dist\ReverseSolitaire.exe
```

配布するときは **この `ReverseSolitaire.exe` だけをコピー**してください。

> 未署名の自作EXEでは、Windows SmartScreen やウイルス対策ソフトが初回に確認を表示する場合があります。

## 4枚の基準例

反転前が上から次の4枚の場合:

1. A♣（数字・マーク表示）
2. カードA（裏面）
3. 9♥（数字・マーク表示）
4. カードB（裏面）

下へひっくり返した後は、上下順が逆転し、各カードの表裏も反転して上から次の順になります。

1. カードB（数字・マーク表示）
2. 9♥だったカード（裏面）
3. カードA（数字・マーク表示）
4. A♣だったカード（裏面）

つまり、**順番は逆順、各カードの表裏も反転**が基準ルールです。
