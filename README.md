# Reverse Solitaire v0.1.8

高校生の頃に考えた「記憶 + ソリティア」型トランプゲームです。

## 現在のルール

1. 通常のトランプ52枚をシャッフルします。
2. 1組6枚を基本として、6枚×8組 + 最後の4枚の1組、合計9組に分けます。
3. 各組のカードは上下に大きめにずらして重ね、表向きカードの数字とマークが見えるようにします。
4. 初期状態では各組のカードを表・裏・表・裏...と交互に配置します。
5. 「ひっくり返す」は、実物のトランプの束を机の上でドミノ倒しのように180°倒す動作です。
   - 下方向へひっくり返す時は、山全体が支点を越えて **下側へ実際に移動**します。
   - 次に上方向へひっくり返す時は、同じ支点を越えて **上側へ戻ります**。
   - 反転後の見た目の上下順は、反転前の完全な逆順になります。
   - 以前の「論理的な一番上」を残すための補正は行いません。カードの物理的な180°移動そのものが上下順を決めます。
   - ひっくり返した後は、その山のカードはすべて数字とマークが読める表向き状態になります。
6. 選択できるのは、その山で物理的に一番上に露出しているカードです。
7. 1枚目を選び、2枚目をクリックした時点で同じ数字なら自動的に2枚を取り除きます。スートは違っていて構いません。
8. ペアが違った場合は短いフィードバックの後に選択を解除します。
9. 全52枚を取り除けばクリアです。
10. 続行困難と判断したら「ギブアップ」で終了できます。

## 4枚の基準例

ユーザー提示の物理イメージを回帰条件として固定しています。

反転前の山を、支点側から自由端側へ次の4枚だとします。

1. 1番目のカード（裏）
2. J♥（表）
3. 3番目のカード（裏）
4. 9♦（表・一番下側/自由端）

下へ180°ひっくり返した後の見た目は、上から順に次の通りです。

1. **9♦** が一番上
2. **元の3番目のカード** が2番目
3. **J♥** が3番目
4. **元の1番目のカード** が一番下

反転後は4枚とも数字とマークが見える状態です。

## アニメーション

- 初回は `ひっくり返す ↓` で、山の下端を支点にカード束全体が下へ倒れ込みます。
- 反転後は `ひっくり返す ↑` になり、同じ支点を使って上へ戻ります。
- 約90°の中間点ではカード束がほぼ水平線に見えます。
- `cos(angle)` の符号を保った投影により、各カードは支点を越えて反対側へ移動します。
- その結果、カードの見た目の上下順が自然に逆転します。
- ペア成立時は、2枚のカードが縮みながら消えるアニメーションを表示します。

### ちらつき対策

Tkinter Canvas のフレーム更新では、旧フレームを先に全面消去せず、次フレームを完成させてから旧フレームを破棄します。
CRT の走査線でいう帰線期間、現代のゲーム描画でいう VSync / ダブルバッファに近い考え方で、途中の空画面をユーザーへ見せないようにしています。

## 起動方法（Windows）

```bat
run_game.cmd
```

または:

```bat
py src\reverse_solitaire\app.py
```

## 回帰テスト

```bat
check_harness.cmd
```

`pytest` が未インストールの場合は `check_harness.cmd` が自動インストールを試みます。

## 開発ガードレール

ゲームルール上の不変条件は `harness/app_blueprint.yaml` に記録しています。
ルール変更を伴わない修正では、この不変条件と既存テストを維持します。
