# Reverse Solitaire v0.1.9

高校生の頃に考えた「記憶 + ソリティア」型トランプゲームです。

## 現在のルール

1. 通常のトランプ52枚をシャッフルします。
2. 1組6枚を基本として、6枚×8組 + 最後の4枚の1組、合計9組に分けます。
3. 各組のカードは上下に大きめにずらして重ね、表向きカードの数字とマークが見えるようにします。
4. 初期状態では各組のカードを表・裏・表・裏...と交互に配置します。
5. 「ひっくり返す」は、実物のトランプの束を机の上でドミノ倒しのように上下へ倒す動作です。
   - 下方向へひっくり返す時は、山全体が支点を越えて下側へ移動します。
   - 次に上方向へひっくり返す時は、同じ支点を越えて上側へ戻ります。
   - **カードの上下の並び順は変えません。** 1番目は1番目、2番目は2番目のままです。
   - 代わりに、各カードの表裏をすべて切り替えます。
   - 数字とマークが見えていたカードは裏柄になり、裏柄だったカードは数字とマークが見えるようになります。
6. 選択できるのは、その山で見た目上一番上にあるカードです。裏向きでも、覚えている数字を頼りに選択できます。
7. 1枚目を選び、2枚目をクリックした時点で同じ数字なら自動的に2枚を取り除きます。スートは違っていて構いません。
8. ペアが違った場合は短いフィードバックの後に選択を解除します。
9. 全52枚を取り除けばクリアです。
10. 続行困難と判断したら「ギブアップ」で終了できます。

## 4枚の基準例

ユーザー提示のイメージを回帰条件として固定しています。

反転前を上から順に次の4枚とします。

1. A♣（数字とマークが見える）
2. カードA（裏柄）
3. 9♥（数字とマークが見える）
4. カードB（裏柄）

ひっくり返した後も、カードの上下位置は同じです。

1. A♣だったカード（裏柄）
2. カードA（数字とマークが見える）
3. 9♥だったカード（裏柄）
4. カードB（数字とマークが見える）

つまり、**カードの位置は維持し、表裏だけを反転**します。

## アニメーション

- 初回は `ひっくり返す ↓` で、山全体が下方向へ倒れ込みます。
- 反転後は `ひっくり返す ↑` になり、次は上方向へ戻ります。
- 約90°の中間点ではカード束がほぼ水平線に見え、その見えにくい瞬間に各カードの表裏を切り替えます。
- 山全体は支点を越えて上下に移動しますが、各カードの相対的な上下順は変えません。
- ペア成立時は、2枚のカードが縮みながら消えるアニメーションを表示します。

### ちらつき対策

Tkinter Canvas のフレーム更新では、旧フレームを先に全面消去せず、次フレームを完成させてから旧フレームを破棄します。
CRT の走査線でいう帰線期間、現代のゲーム描画でいう VSync / ダブルバッファに近い考え方で、途中の空画面をユーザーへ見せないようにしています。

## 起動方法（Windows）

```bat
run_game.cmd
```

または:

```bat
py src\reverse_solitaire\app.py
```

## 回帰テスト

```bat
check_harness.cmd
```

`pytest` が未インストールの場合は `check_harness.cmd` が自動インストールを試みます。

## 開発ガードレール

ゲームルール上の不変条件は `harness/app_blueprint.yaml` に記録しています。
ルール変更を伴わない修正では、この不変条件と既存テストを維持します。
