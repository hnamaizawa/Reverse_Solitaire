# Reverse Solitaire v0.1.1

高校生の頃に考えた「記憶 + ソリティア」型トランプゲームを、まず遊べる形にした初期実装です。

## 現在のルール解釈

1. 通常のトランプ52枚をシャッフルします。
2. 1組8枚を基本として、合計7組（最後だけ4枚）に分けます。
3. 各組のカードは少しずつ下へずらして重ねます。
4. 各組では、下から上へ **表・裏・表・裏...** と交互に配置します。
5. 各組の「ひっくり返す」を押すと、**カードの位置や並び順は一切変えず、その場所にある全カードの表裏だけを反転**します。
   - これまで見えていたカードが見えなくなり、見えていなかったカードが見えるため、記憶要素が生まれます。
6. 選択できるのは **各組の一番上にあり、かつ表向きのカード** だけです。
7. 同じ数字（A,2,...,10,J,Q,K）のカードを2枚選ぶと取り除けます。スートは違っていて構いません。
8. 全52枚を取り除けばクリアです。
9. 続行困難と判断したら「ギブアップ」で終了できます。

## 起動方法（Windows）

Python 3 がインストール済みであれば、追加GUIライブラリは不要です（Tkinterを使用）。

```bat
run_game.cmd
```

または:

```bat
py src\reverse_solitaire\app.py
```

## 回帰テスト

```bat
check_harness.cmd
```

`pytest` が未インストールの場合は、`check_harness.cmd` が自動的に `py -m pip install pytest` を実行します。自動インストールに失敗した場合だけ、画面に表示されたコマンドを手動で実行してください。

## 開発ガードレール

ゲームルール上の不変条件は `harness/app_blueprint.yaml` に記録しています。
ルール変更を伴わない修正では、この不変条件と既存テストを維持します。

## まだ調整可能な点

- 8枚×何組にするか（52枚全部を使うか、48枚などにするか）
- 最初の一番上が裏向きの組を許すか
- 手詰まりを自動判定するか（現状はプレイヤーがギブアップ）
- 取り除いた後に空いた組へカードを移動できるか（現状は不可）

実際に遊んだ感触から、元のアイデアに合わせてルールを詰めていきます。
